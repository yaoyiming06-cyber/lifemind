# 文本与 PDF 笔记组织统一

用户已要求直接修改，使文本具有 PDF 的目录涵盖、编号、排序和续号行为。

所有 v2 来源共用本地编译规则：新笔记至少进入技术栈下带编号的二级主题目录，标题使用章号和知识点号；章节标题保留原有章号。PDF 以 pageCoverage 的首次页码排序，文本、Markdown、网页及代码以原文标题和证据位置排序，无法匹配时保持模型顺序。父主题先于其分支。短文本也执行这些规则，不依赖 5000 字整合迁移门槛。

续号读取本次技术栈的 Vault 笔记；同一批次同根目录共享计数，避免多来源重复编号。已编号的目录可沿用并为新主题分配后续目录号。合并既有笔记保留目标标题和路径；既有迁移计划的目标目录与最终新笔记目录保持一致。真实 Vault 写入仍须用户在应用中确认。

保留 PDF 公式、页证据和内嵌图片专用校验；不改动模型配置和视觉分批限制。覆盖真实编译、双链、预览和写入计划，不通过全量松开校验修复组织问题。
