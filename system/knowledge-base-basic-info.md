# lifemind 知识库基础信息

本文件仅供系统内部维护知识库基础状态，不作为面向用户的概览页面展示。

## 当前用途

- 记录 Vault 基础路径、技术栈目录、索引文件位置等系统级信息。
- 给后续扫描、归类、写入脚本提供稳定的基础上下文。
- 避免在用户界面里维护一个会随知识库膨胀而失去价值的总览页。

## 初始字段

- vault_path: 待用户选择
- memory_index: vault_memory.md
- taxonomy_source: system initialized
- last_scan_at: empty
- ignored_suggestions: empty
